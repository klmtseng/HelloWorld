# Short-term Index Prediction Project

This folder contains code and documentation for predicting short-term index
futures using ARIMA and machine learning methods. It provides a simple
starting point with daily data but can be extended to intraday data.

## Files

- `forecast.py` — Example script demonstrating how to train an ARIMA model and
a gradient boosting model with rolling window evaluation.

Place your historical price data in `data/index_daily.csv` before running the
script.
